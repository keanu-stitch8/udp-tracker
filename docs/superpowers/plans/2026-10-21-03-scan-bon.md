# Rencana 3: Scan Bon — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline). Steps use checkbox (`- [ ]`). Rencana ringkas (preferensi pengguna): kode lengkap hanya untuk bagian yang tidak jelas; sisanya mengikuti pola modul yang sudah ada.

**Goal:** Foto/PDF bon bisa dilampirkan ke transaksi, discan Gemini untuk mengisi nominal/tanggal/toko/kategori, dan ditampilkan lagi di form & daftar transaksi.

**Architecture:** Modul baru `src/modules/receipts` (adapter `api/blob.ts` + `api/gemini.ts`, mapper zod hasil scan, service scan). Satu endpoint upload+scan; lampiran disimpan ke tabel `attachments` saat transaksi disimpan (input `attachments`). Store Blob **private**, jadi gambar disajikan lewat route app yang mengecek sesi.

**Tech Stack:** `@vercel/blob` 2.8 (sudah terpasang di branch `feat/scan-bon`), Gemini REST `generateContent`, zod 4, Drizzle, TanStack Query, vitest + PGlite.

## Keputusan (berbeda dari spec §6.1, dicatat ke spec di Task 7)

1. **Store Blob private** (terbukti 2026-10-21: `put` public ditolak, private OK). Gambar → `GET /api/projects/[projectId]/attachments/[attachmentId]` (stream dari `get(pathname, { access: "private" })`). Pratinjau sebelum simpan memakai `URL.createObjectURL` di browser.
2. **Upload lewat server, satu request**: `POST /api/projects/[projectId]/receipts` (multipart `file`) → `put` ke Blob + scan Gemini dari byte yang sama → `{ attachment, scan }`. Tidak perlu client token, dan HP hanya mengunggah sekali. Konsekuensinya batas file **4 MB** (batas body fungsi Vercel 4,5 MB). Gambar sudah dikompres jadi ±300 KB; PDF > 4 MB ditolak dengan pesan jelas.
3. **Model** `GEMINI_MODEL` default `gemini-flash-latest` (saat ini → `gemini-3.8-flash`). Satu panggilan teks butuh ±10 detik, jadi **timeout 30 detik** (spec: 15) dan `thinkingConfig.thinkingLevel: "low"`.
4. Lampiran yang diunggah tapi transaksinya batal disimpan menjadi blob yatim → `scripts/cleanup-blobs.mts` (spec §3.4 menyebut `.ts`; ikut pola `.mts` repo).

```ts
export async function putReceipt(pathname: string, body: Blob, contentType: string) {
  return put(pathname, body, { access: "private", contentType, addRandomSuffix: false });
}
export async function readReceipt(pathname: string) {
  return get(pathname, { access: "private" });
}
/** Best effort: gagal hapus hanya dicatat, blob yatim dibersihkan `npm run blob:cleanup`. */
export async function deleteReceipts(pathnames: string[]) {
  if (!pathnames.length) return;
  await del(pathnames).catch((error) => console.error("[blob] gagal hapus", pathnames.length, error));
}
```
